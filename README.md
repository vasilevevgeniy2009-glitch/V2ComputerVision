🤺 HEMA Virtual Trainer
Система компьютерного зрения для объективного анализа техники исторического фехтования (HEMA). Проект использует нейросетевые модели для оценки позы спортсмена, контроля равновесия, расчета дистанции и определения границ тренировочной зоны в реальном времени.
📖 Описание
Традиционные методы тренировки в HEMA часто субъективны и зависят от внимания тренера. Данная система автоматизирует анализ биомеханики, выявляя ошибки в стойке и движениях, которые сложно заметить при обычном просмотре. Решение работает на стандартном оборудовании (веб-камера + ПК) и не требует дорогостоящих датчиков.
✨ Основные возможности
Оценка позы: Детекция 17 ключевых точек тела в реальном времени.
Контроль равновесия: Анализ центра масс относительно площади опоры (лодыжек).
Расчет дистанции: Вычисление расстояния между спортсменами по 6 парам ключевых точек (плечи, бедра, колени).
Границы ринга: Автоматическое определение зоны тренировок через цветовую сегментацию (HSV) и коррекцию перспективы.
Визуализация: Отображение аналитических данных поверх видеопотока (линии баланса, зоны дистанции).
Запись: Сохранение тренировочного видео с наложенной аналитикой.

🏗 Архитектура
Проект построен на принципах ООП и разделен на два основных модуля:
MultiTaskVisionSystem — базовый класс. Отвечает за захват видео, загрузку моделей YOLO, управление циклом обработки кадров, переключение режимов и контроль FPS.
ElectronicTrainer — класс предметной логики. Содержит алгоритмы для HEMA: расчет дистанции, проверка границ ринга, анализ баланса и стоек.
