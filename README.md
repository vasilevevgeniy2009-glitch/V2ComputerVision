🤺 HEMA Virtual Trainer

Система компьютерного зрения для объективного анализа техники исторического фехтования (HEMA). Она использует нейросетевые модели в реальном времени, чтобы оценивать позу спортсмена, контролировать равновесие, рассчитывать дистанцию и определять границы тренировочной зоны.

- Визуализация: Отображение аналитических данных поверх видеопотока (линии баланса, зоны дистанции).
- Запись: Сохранение тренировочного видео с наложенной аналитикой.

🛠 Технологический стек:

- Язык: Python 3.x.
- Computer Vision: OpenCV, NumPy.
- Neural Networks: YOLOv11 (yolo11s.pt, yolo11s-pose.pt).
- Сборка: PyInstaller (создание .exe).
- Среда: PyCharm, venv.
- Контроль версий: Git / GitHub.

🏗 Архитектура

Проект построен на принципах ООП и состоит из двух основных модулей:

- MultiTaskVisionSystem — базовый класс для захвата видео, загрузки моделей YOLO, управления циклом обработки кадров, переключения режимов и контроля FPS.
- ElectronicTrainer — класс предметной логики, содержащий алгоритмы для HEMA: расчет дистанции, проверка границ ринга, анализ баланса и стоек.

🚀 Установка и запуск:

1. Клонирование репозитория.
2. Создание виртуального окружения.
3. Установка зависимостей.
4. Запуск системы.

⌨️ Управление

В режиме реального времени доступны следующие команды:

- Клавиши 1, 2, 4 и 5 для переключения режимов анализа.
- Клавиша Q для выхода из программы и сохранения видео.

⚙️ Настройки производительности

Для обеспечения высокого FPS входное разрешение нейросети ограничено до 320x320 пикселей. Рекомендуется использовать GPU для ускорения работы моделей YOLO.
